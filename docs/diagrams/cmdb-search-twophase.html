1. 原生 3-gram 滑窗切词机制 Ngram Tokenizer
突破通用中文分词器无法处理 IP、短编码的限制，连续滑窗生成倒排词根：
输入: "192.168.1.100"
分词: ["192", "92.", "2.1", ".16", "168", ...]
优势: 免搭 ES 集群，无需维护 Logstash 同步链路
2. 通配文本索引平铺存储 c_resources
全模型资产实例平铺存储，自定义字段动态汇入 data 映射：
索引定义: { "$**": "text" }
分词插件: default_language: "ngram"
特性: 通配捕获所有动态属性，随写随搜
3. 纯数值聚合与全域穿透 Pipeline Optimizer
通过上下文注入穿透指令，保障超管大盘性能稳定：
超管模式: mongox.IgnoreTenantContext(ctx)

内存防线: 零 $push 实体物化，彻底杜绝 OOM
