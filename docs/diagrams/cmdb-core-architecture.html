Layer 2 ECMDB Core 领域核心服务引擎
领域能力收敛 · 零 DDL 动态模型 · 高性能读写调度
元模型引擎 (Model)
Meta Engine
▪ 三级元模型：模型 -> 属性分组 -> 自定义字段
▪ 字段级校验：必填/唯一性/正则 (IP, CIDR, Email)
▪ 丰富类型系统：Basic, Enum, Secure, Ref 引用
▪ 多维空间隔离：系统内置、租户隔离与分类标签
统一资产引擎 (Resource)
Storage Engine
▪ 根文档平铺内联：bson:",inline" 零 DDL 随写随存
▪ 原子属性读写：原生 $set / $unset 局部更新
▪ 通配全文检索：$** 3-gram 原生倒排分词检索
▪ 批量与过滤：高自由度复合索引极速范围过滤
关系拓扑引擎 (Relation)
Graph Engine
▪ 拓扑类型约束：定义源与目标约束 (如 主机 -> 网卡)
▪ 双向图谱解析：上下游资产级联依赖与影响面追溯
▪ 级联路径合成：跳板机/代理链路自动图谱寻路合成
▪ 批量拓扑维护：资产创建/解绑自动维护边关系生命周期
🛡️ 敏感凭据安全统管中心 IResourceProtector
AES-GCM-256 落盘加密
列表全量检索自动脱敏置空
插件运维直连瞬态内存解密
Layer 3 底层数据持久化与高速缓存引擎
无外部搜索引擎依赖 · 原生高性能文档存储与热点加速
🍃 Percona MongoDB 7.0+ (原生 ngram 检索) Primary Datastore
c_models & c_attributes 存储动态元模型描述、属性分组与字段验证规则
c_resources 统一资产平铺内联集合 + $** 通配倒排文本索引
c_relations & types 资产双向关系拓扑网络与约束规则元数据
⚡ Redis 7.0+ 基础设施 Cache & Lock
Redlock 分布式锁：防止并发模型定义与迁移竞争
元模型热点缓存：高频资产读写零延迟元数据校验
租户配额与会话：API 访问限流与多租户并发隔离
服务定位: 数字资产中枢与动态元数据驱动 技术底座: Golang 1.25 / Percona MongoDB 7.0+ 解耦插件生态: ecmdb-plugins 独立微服务直连
